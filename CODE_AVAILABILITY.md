# Code availability text

## Manuscript-ready statement for the revision

All analytical and plotting code used to generate the reported results has been provided to the editors and referees as an anonymized software archive. The archive includes environment specifications, a data and code manifest, figure source-data tables, and scripts for data harmonization, temporal and spatial analyses, XGBoost-SHAP calculations, standardized pathway analysis, validation and figure generation. The editor-requested ALLUMs reproduction, product controls, flux-site validation and GLASS-to-MCD43A3 contribution sensitivity are consolidated in `src/validation/03_editor_revision_controls.py`. If the Article is published, the complete versioned archive will be deposited in a DOI-minting repository and the persistent identifier will be added to the published Code availability statement. Third-party satellite and reanalysis data will remain available from their original providers under the access conditions described in the Data availability statement.
