# Response to editor comment 2

**Editor comment:** You must make all of your analytical and plotting codes available for anonymous peer review and commit to making them available in a DOI-minting repository in the event of publication.

**Response:** We agree and have supplied a complete anonymized software archive for editorial and peer review. The archive contains the retained code used to (i) process GLASS blue-sky albedo and apply the common ERA5-Land mask, (ii) harmonize the annual gridded predictors, (iii) calculate the temporal and spatial results in Fig. 2, (iv) calculate the surface-energy-partitioning diagnostics in Fig. 3, (v) fit the background and land-surface XGBoost models and calculate SHAP contributions in Fig. 4, (vi) perform the full-record standardized pathway analysis, and (vii) generate the main and supplementary figures. We also provide environment specifications, compact figure source data, a data inventory, a figure-to-code map, a machine-readable manifest and SHA-256 checksums. Large third-party satellite and reanalysis datasets are not redistributed, but their sources, variables, expected file structure and roles are documented.

If the Article is published, we commit to depositing the accepted, versioned code archive and its compact source-data package in a DOI-minting repository. The resulting DOI will be added to the published Code availability statement. We have not inserted a provisional or fabricated DOI in the revision.
